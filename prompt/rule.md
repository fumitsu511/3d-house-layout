### 家の間取りを3dで見れるwebアプリを作成する

## 前提条件
# 本ルールは絶対であり、変更不可
# 本ルールはすべての回答に対して適用される

## アーキテクチャ
# node.js
# react
# Three.js
# その他は任意

## 要件
# ユーザーは3dで家を見ることができる
# ユーザーは家を動かすことができる
# ユーザーは家を回すことができる
# ユーザーは家を縮めることができる
# ユーザーは家を拡大することができる
# ユーザーは家を削除することができる
# ユーザーは家の中を移動できる
# ユーザーは家の大きさを変更できる
# ユーザーは家の間取りを変更できる
# ユーザーは家の床や壁の色を変更できる
# ユーザーはドアや窓の位置を変更できる
# ユーザーは家の間取りを保存できる
# ユーザーは家の間取りを読み込むことができる
# ユーザーは家具を配置できる
# ユーザーは家具を動かすことができる
# ユーザーは家具を回すことができる
# ユーザーは家具を削除することができる
# ユーザーは家具を複製することができる
# ユーザーは家具を複製して別の場所に移動して削除することができる
# ユーザーは壁を自由に作成できる
# ユーザーは壁を削除できる
# ユーザーは壁を動かすことができる
# ユーザーは壁を回すことができる
# ユーザーは壁を縮めることができる
# ユーザーは壁を拡大することができる
# ユーザーは壁を色を変更できる
# ユーザーは壁を透明にすることができる
# ユーザーは壁を不透明にすることができる
# ユーザーは壁を削除することができる
# ユーザーは壁を複製することができる
# ユーザーは壁を複製して別の場所に移動して削除することができる
# 家の大きさはメートルで指定することができる
# 家の間取りは四角形以外の形状を作成できる
# 家の間取りは複数の四角形を組み合わせて作成できる
# 家の間取りは複数の四角形を組み合わせて複製して別の場所に移動して削除することができる
# 部屋や壁が空中に浮かないようにする
# 壁の色は半透明にする
# 壁や床の大きさを自由に変更できる
# 壁や床の大きさを表示する
# 部屋全体広さを画面上部に表示したい
# 部屋の高さを表示したい
# 部屋の高さを変更したい
# 部屋の高さを変更するときに、壁の高さも変更する
# 家具は配置する際は空中に浮かないようにする
# 家具は配置する際は壁の内側に配置する
# 家具は配置する際は床の上に配置する
# ユーザーは床や壁の大きさを変更できる
# ユーザーは壁の透明度を変更できる
# 床の面積の総和を総面積として表示する
# 床の大きさを変更した際は、総面積を変更する
# 床を追加、削除した際は総面積を変更する
# 日本語表示にする
# 写真をインポートして家具にする
# インポートする家具は、写真から家具以外の余分な背景を削除して家具とする
# インポートする家具は、写真から家具の大きさを自動で推測して家具とする
# インポートする家具は、自動で推測して立体の家具とする
# インポートする家具は、色はそのまま使用する
# インポートした家具もサイズの変更を可能にする
# インポートした家具も位置の変更を可能にする
# インポートした家具も回転を可能にする
# インポートした家具も削除を可能にする
# インポートした家具も複製を可能にする
# インポートした家具も複製して別の場所に移動して除することができる
# 家具の色の変更をできる
# 家具のサイズを変更できる
# 家具はいくつかの種類から選択できる
# https://3d.receno.com/simulator/を参考に実装する
